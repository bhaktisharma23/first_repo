19 aug:
Git fetch vs pull

git fetch downloads information about changes from the remote repository without changing my current branch.

git pull fetches the changes and integrates them into my current branch.

20 aug:
Today I learned git stash :
Git stash temporarily saves uncommitted changes.
Git stash pop restores the saved changes.

21 aug:
Git restore

git restore <file> discards uncommitted changes in a file.
It restores the file to its last committed state.
